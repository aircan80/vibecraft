# Java bootstrap preset and external schema dependency

`Forever70450Bootstrap.wagoManifest()` returns the reviewed 51-table Wago request manifest for exact Forever beta build `1.60.1.70450`, product `wow_classic_beta`, locale `enUS`. Its resource contains table names and SHA-256 metadata only. The code verifies its canonical aggregate against the conservative overlay's base contract before returning immutable pins. This is a frozen supported preset, not a claim that this is the latest build or that other builds share these hashes. Constructing it grants no network permission.

`PinnedItemSparseDefinitionMaterializer` acquires the external schema from the exact 40-character WoWDBDefs commit URL declared by `PinnedItemSparseDefinition.SOURCE`. It checks the reviewed SHA and full supported layout parser before publication. The schema is not bundled in source or the application. Applicable upstream notices and attribution remain relevant; acquisition is not a legal clearance claim.

The materializer requires independent `ALLOW_RAIDBOTS_HOTFIX` permission. The future source-selection description must disclose that this optional source also downloads its reviewed ItemSparse schema definition from GitHub/WoWDBDefs. Wago or Blizzard CDN permission does not authorize this dependency automatically.

A protected job cache holds complete definition directories and an atomically replaced current pointer. Reuse checks source/provider/commit/hash/layout/build metadata and actual schema bytes without network. Malformed or stale cached metadata is recoverable through a fresh authorized download; it is never relabeled as verified historical acquisition. Interrupted, invalid, oversized, redirected or timed-out responses cannot publish a complete pointer, and previous complete files remain. Reads and transport are bounded to 1 MiB with cancellation polling, including stalled HTTP bodies. No fallback provider or build is contacted.

The API returns `Result(definition, evidence, reused)`. Callers can pass the acquired definition bytes and `Forever70450Bootstrap.wagoManifest()` into the independently consented conservative overlay materializer. This removes developer-local manifest/schema files from the future bootstrap path. Source-plan selection, composite job orchestration, readiness gates, GUI progress and activation remain separate integration work; this slice does not enable the setup Build action.

Validation used authored loopback fixtures plus a genuine Java request for the reviewed pinned schema: 75,858 bytes, exact SHA/layout accepted, followed by verified zero-network cache reuse. Eleven focused tests cover the production metadata preset, consent, cache reuse and malformed metadata recovery, corrupt content, failed replacement preservation, hashes/parser rejection, redirects, size limits, cancellation and stalled responses.
