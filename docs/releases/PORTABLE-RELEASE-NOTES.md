Vibecraft is a World of Warcraft companion for exploration, loot, crafting, and lore.

Download the archive for your operating system and CPU, extract it, and launch Vibecraft. Java 21 is included; no separate Java, Python, Node, or Blender installation is needed. The application ships without a game dataset. On first run, build your library from the sources you explicitly select and permit.

- Linux x64: extract the tar.gz and run `Vibecraft/bin/Vibecraft`.
- Windows x64: extract the ZIP and run `Vibecraft/Vibecraft.exe`.
- macOS Apple silicon or Intel: extract the matching tar.gz and open `Vibecraft.app`.

These portable builds are unsigned and macOS builds are not notarized. Your operating system may display an unrecognized-developer warning. SHA256 files and platform verification JSON accompany each archive. Native offline startup checks validate the bundled runtime and SQLite loading; they do not certify every GUI workflow or live data source.
