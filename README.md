# WoW Forever Item & Drop Browser

A Swing desktop application for browsing World of Warcraft items and where they drop, backed by a shipped SQLite database that is built from community addon data.

## Build

```
./mvnw -B verify
```

## Run

```
java -jar app/target/wow-forever-browser.jar
```

## Rebuild the data

The shipped database `app/src/main/resources/data/wowforever.sqlite` is generated by the `importer` module from two pinned upstream sources: QuestieDB at commit `49e7dbc` and AtlasLootClassic at commit `8e99341`. The pins live in `importer/src/main/resources/dev/wowforever/importer/sources.properties`.

Build the importer, then run it from the repository root:

```
./mvnw -B -pl importer -am package -DskipTests
java -jar importer/target/importer.jar --out app/src/main/resources/data/wowforever.sqlite --fail-on-unsupported
```

The same import runs inside Maven with `./mvnw -B -pl importer -am -Pimport-data verify`.

- **Download cache.** Upstream files are downloaded once into `~/.cache/wowforever-importer` and reused afterwards. Use `--cache <dir>` to put the cache elsewhere, or `--questiedb-dir` and `--atlasloot-dir` to read local checkouts instead.
- **`--fail-on-unsupported`.** The importer exits with code 2 when a correction could not be applied to a field the browser shows. Always pass it when refreshing the shipped database.
- **Outputs.** The importer writes `import-report.txt` and `build-id.txt` beside the database. Commit all three files together.

The committed build has these headline row counts:

| Table | Rows |
|---|---|
| item | 21,543 |
| npc | 13,392 |
| item_npc_drop | 164,447 |

Known gaps in the upstream data, as of this build:

- **Unknown-NPC references.** 325 `item_npc_drop` rows name an NPC id that is not in the NPC table.
- **Nameless stubs.** 249 items and 1 game object have no name. The items exist only because a QuestieDB correction gives them a quest-start link, and none of them is searchable.
